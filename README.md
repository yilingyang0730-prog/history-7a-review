# 七上歷史 第 1–2 課 複習（翰林版）

國中歷史七年級上學期（108 課綱、翰林版）第 1–2 課的互動式複習講義與測驗。

- 第 1 課：史前臺灣與原住民文化（1-1、1-2）
- 第 2 課：大航海時代各方勢力的競逐（2-1、2-2）

## 功能

- **講義**：重點表格、史前文化地層圖、易混淆整理
- **測驗**：60 題（單選 44、是非 10、題組 6），滿分 100 分
  - 練習模式：即時對答＋解析
  - 考試模式：交卷後計分，並列出各小節答對題數
  - 可依小節出題、只看錯題
- 作答紀錄只存在使用者自己的瀏覽器

## 使用

直接開啟網頁即可使用。內容依一般國中歷史教材整理，年代與用詞請以學校課本為準。
